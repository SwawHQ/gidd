GIDD prerequisites preparation (Windows x64 / PowerShell 5.1)

  gidd.pre.ensure help en            #Show English help
  gidd.pre.ensure help zh            #Show Chinese help
  gidd.pre.ensure --repo <repository-path>  #Ensure JS runtime, Git and gh are available; create the repository's gidd.link.cmd
  gidd.pre.ensure --repo <repository-path> --jsruntime=node  #As above, selecting Node (otherwise Bun is preferred)
  gidd.pre.ensure --repo <repository-path> --force           #Download and set up portable copies of the JS runtime, Git and gh again
  gidd.pre.ensure --repo <repository-path> --check           #Check availability (read-only)
