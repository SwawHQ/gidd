GIDD（Windows x64 / PowerShell 5.1）

帮助与诊断：
  gidd help en                           Show English help
  gidd help zh                           显示中文帮助
  gidd doctor                            可用性诊断

技能设置：
  gidd config show                       列出 config.toml 当前内容
  gidd config set <字段> <值>            设置 config.toml 中指定字段的值
  gidd config set github.account SwawHQ  (示例) 设置 github.account 的值为 SwawHQ

GitHub 身份：
  gidd identity                          按配置检查 API 身份、Git 远程读取和提交作者
  gidd auth                              按配置申请设备授权并等待确认；gh 可能保存凭据

外部工具：
  gidd tools --check                     只读检查 Git、gh、JS 运行时（Bun 或 Node）及共享绑定
  gidd tools --ensure                    确保 JS 运行时、Git、gh 可用并修复绑定；缺失时下载便携版
  gidd tools --ensure --jsruntime=node   同上，但指定 JS 运行时为 Node；未指定时复用当前运行时
  gidd tools --ensure --force            重新下载选定运行时、Git、gh 的便携版，重装并重建绑定
