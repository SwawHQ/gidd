GIDD 仓库工具准备 (Windows x64 / PowerShell 5.1)

帮助：
  gidd.tools.ensure.cmd help en                              Show English help
  gidd.tools.ensure.cmd help zh                              显示中文帮助
  gidd.tools.ensure.cmd --help                               显示帮助；也支持 -h 和不带参数

仓库准备：
  gidd.tools.ensure.cmd --repository <目标仓库绝对路径>         确保 JS 运行时、Git、gh 可用，并创建仓库专用 gidd.link.cmd
  gidd.tools.ensure.cmd --repository <目标仓库绝对路径> --jsruntime=node  选择 Node；--jsruntime=bun 选择 Bun
  gidd.tools.ensure.cmd --repository <目标仓库绝对路径> --force  重新下载并安装所选运行时、Git、gh 的受管副本

要求与结果：
  --repository 必须是已有 Git 工作树的本地绝对根目录，并具备 GitHub remote；不接受仓库子目录。
  健康工具和内容相同的入口直接复用；此入口不接受 --check 或 --ensure。
  创建 <目标仓库>/.agents/skills/gidd/gidd.link.cmd；可从任意目录调用，目标固定为其所属仓库。
  准备结果以 JSON 输出；不会创建或修改 config.toml、初始化 Git 或登录 GitHub。

帮助语言：
  显式语言 > GIDD_LANG > LC_ALL > LC_MESSAGES > LANG > 系统界面语言；其他系统语言使用英文。
  查看帮助无需 --repository 或 JS 运行时，不准备工具、不写入文件。
