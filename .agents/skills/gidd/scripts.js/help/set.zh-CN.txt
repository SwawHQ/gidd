GIDD 配置

  gidd.link set.show                #校验并显示 config.toml 内容（JSON）
  gidd.link set <字段> <值>     #设置一个字段
  gidd.link clear <字段>        #删除一个字段；已不存在则成功
  gidd.link set                 #显示本帮助，不读取或修改配置

可编辑字段：
  repo.remote.name       本地 Git 远端名，例如 origin
  repo.remote.url        HTTPS 仓库标识，例如 https://github.com/owner/repo
  repo.remote.account    GitHub 登录名，例如 Octocat
  git.user.mode          必填：managed|inherit
  git.user.name          managed 模式下与邮箱成对必填；inherit 模式下必须删除
  git.user.email         managed 模式下与姓名成对必填；inherit 模式下必须删除
  git.credential.mode    必填：gh|inherit（gh 提供 HTTPS 凭据）
  spec.mode              规范名；运行 gidd.link spec 列出可选规范

set 和 clear 可逐字段修改，使用 set.show 或 .git/.gh 前需满足所选模式的要求。
空字符串仍按字段规则校验，不表示删除。
含空格的值需加引号：gidd.link set git.user.name "Commit Name"
切换为继承 Git 身份：
  gidd.link clear git.user.name
  gidd.link clear git.user.email
  gidd.link set git.user.mode inherit
