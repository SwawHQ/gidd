GIDD 仓库开发（Windows x64 / Windows PowerShell 5.1）

  dev.cmd .help [zh|en]          显示帮助，不需要 Bun/Node，不下载。
  dev.cmd .info                  分别报告开发 Bun 和 Node。
  dev.cmd .setup bun            只准备 Bun，优先复用，否则按配置下载安装。
  dev.cmd .setup node           只准备 Node，优先复用，否则按配置下载安装。
  dev.cmd .setup                同时准备开发测试需要的 Bun 和 Node。
  dev.cmd .test [测试组]         用 Bun 和 Node 分别执行同一套离线测试。
  dev.cmd .test-bun [测试组]     只运行 Bun 测试。
  dev.cmd .test-node [测试组]    只运行 Node 测试。
  dev.cmd .test-live            两种运行时验证官方下载、安装及已有工具复用。
  dev.cmd .auth                 按 config.toml 中的主机和账号申请设备授权。
  dev.cmd bun [参数...]         只使用共享目录中的便携 Bun，不回退到 PATH。
  dev.cmd node [参数...]        只使用共享目录中的便携 Node，不回退到 PATH。
  dev.cmd sys bun [参数...] 只使用 PATH 中的 Bun。
  dev.cmd sys node [参数...] 只使用 PATH 中的 Node。

测试组：all（默认）、doctor、setup、process、dev、config、github、entry。
每组显示结果和耗时，失败汇总附带 PowerShell 复跑命令。
开发中按组验证，提交前运行完整 .test。
无参数显示帮助。帮助语言按参数、GIDD_DEV_LANG、系统语言、英文的顺序选择。
.setup 和 .test-live 可以下载工具；.auth 需要产品 tools --ensure 已生成启动器。.test 不安装工具。
bun/node 保留调用目录、参数和输入输出；具体命令可以有自己的网络和写入行为。
便携与 sys 模式互不回退，两者均使用内部兼容检查方法。
工具固定存放于 ~/.agents/skills.tools/gidd/；下载来源读取仓库 config.toml。
缺失时默认下载 Node LTS、Bun 稳定版；已有可用工具继续复用。
安装按配置联网下载或复用已有工具；不接受本地安装包目录。
Node 仅包含运行时和许可证，不附带 npm；当前测试无 npm 依赖。
.auth 可以保存 gh 凭据，不打开浏览器、不设置 Git 凭据助手。
测试不发起登录；所有入口均不启用 GIDD，不修改用户技能或系统 PATH。
产品 JavaScript 仍须同时支持 Node.js 和 Bun。
开发边界、测试适配和清理方式见 DEVELOPMENT.md。
