GIDD (Windows x64 / PowerShell 5.1)

Help and diagnosis:
  gidd help en                           Show English help
  gidd help zh                           Show Chinese help
  gidd doctor                            Check availability

Skill settings:
  gidd config show                       Show current config.toml contents
  gidd config set <key> <value>           Set a field in config.toml
  gidd config set github.account SwawHQ  (Example) Set github.account to SwawHQ

GitHub identity:
  gidd identity                          Check API identity, Git remote read access and commit author using config
  gidd auth                              Request device authorization using config and wait for confirmation; gh may save credentials

External tools:
  gidd tools --check                     Read-only check of Git, gh, JS runtime (Bun or Node) and shared bindings
  gidd tools --ensure                    Ensure JS runtime, Git and gh are available and repair bindings; download portable tools if missing
  gidd tools --ensure --jsruntime=node   As above, but select Node; reuse the current runtime if unspecified
  gidd tools --ensure --force            Download portable copies of the selected runtime, Git and gh again; reinstall and rebuild bindings
