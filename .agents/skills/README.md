# GIDD 技能与规范

[gidd](gidd/SKILL.md) 是本仓库维护并发布的技能，也供当前仓库直接使用。

[specs](gidd/specs/README.md) 按六种开发模式保存 TOML 规范：模式目录定义简介和授权约束，子规范定义各环节的授权。使用 `gidd.link spec.modes`、`spec.list 00` 和 `spec 00/00` 查询与生成提示。

[references/workflow](gidd/references/workflow/README.md) 保存 00～13 共十四个环节的参考经验，按模式和语言选择正文；执行顺序由模式确定。中文仍在整理，英文暂留空，未完成的语言不会生成提示。
