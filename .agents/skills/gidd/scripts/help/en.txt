GIDD (Windows x64 / PowerShell 5.1)

Tool preparation (explicit):
  gidd.cmd bootstrap                                Prepare/repair a JS runtime, Git and gh; publish shared bindings.
  gidd.cmd bootstrap --check                        Check runtime, Git, gh and bindings; no downloads or writes.
  gidd.cmd bootstrap --node                         Select/prepare Node LTS instead of the default Bun preference.
  gidd.cmd bootstrap --reinstall                    Reinstall managed Bun; add --node for Node.

Rerun bootstrap after skill updates or tool path changes. Ordinary commands use shared bindings.

Help and diagnosis:
  gidd.cmd help [en|zh]                              Show help; aliases: --help, -h. Also shown with no arguments.
  gidd.cmd doctor                                    Check environment and target repository; read-only, offline.

Repository config:
  gidd.cmd config show                               Read config.toml without changing it.
  gidd.cmd config set <key> <value>                  Edit a field, preserving comments; create a template if absent.
  gidd.cmd config set github.account <login>         Set the expected account; does not log in or switch accounts.

GitHub identity:
  gidd.cmd identity                                  Check configured API identity, Git remote reading and author.
  gidd.cmd auth                                      Wait for device authorization using config; gh may save credentials.

Documentation:
  SKILL.md / references/                             Full usage, configuration fields, result protocols and current scope.
