GIDD (Windows x64 / PowerShell 5.1)

Tool management (explicit):
  gidd.cmd tools                                    Show this help without a JS runtime.
  gidd.cmd tools --check                            Read-only check of runtime, Git, gh and shared bindings.
  gidd.cmd tools --ensure                           Reuse or prepare/repair a runtime, Git and gh; rebuild bindings.
  gidd.cmd tools --ensure --jsruntime=node          Select Node; --jsruntime=bun selects Bun.
  gidd.cmd tools --ensure --force                   Reinstall the selected managed runtime, Git and gh.

Ensure retains a compatible bound runtime; first preparation defaults to Bun.
Force retains the bound runtime kind unless selected; preserves external tools and the other runtime.
Rerun tools --ensure after skill updates or tool path changes. --check and --ensure are exclusive.

Help and diagnosis:
  gidd.cmd help [en|zh]                              Show help; aliases: --help, -h. Also shown with no arguments.
  gidd.cmd doctor                                    Check environment and target repository; read-only, offline.

Repository config:
  gidd.cmd config show                               Read config.toml without changing it.
  gidd.cmd config set <key> <value>                  Edit a field, preserving comments; create a template if absent.
  gidd.cmd config set github.account <login>         Set the expected account; does not log in or switch accounts.

GitHub identity:
  gidd.cmd identity                                  Check configured API identity, Git remote reading and author.
  gidd.cmd auth                                      Wait for device authorization using config; gh may save credentials.
